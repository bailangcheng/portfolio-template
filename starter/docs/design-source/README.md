# docs/design-source/ —— 上流資料の置き場（読み取り専用スナップショット）

ここには **見た目と文言の上流** を置く。サイトのコードはここを読んで作るが、ここを書き換えない。

| 置くもの | 例 |
| --- | --- |
| 認められた静的稿・ワイヤー | `wireframe-v1/`（HTML / PNG）、Figma の書き出し |
| 公開文言の原本 | `WEBSITE-COPY.md`（3 言語。編集メモは公開文と分けて書く） |
| 書いてよいこと / だめなこと | `CONTENT-BOUNDARY.md`（出してよい事実・出さない名前） |

- 更新は **丸ごと差し替え**、commit に出典と日付を書く。
- `_local/` は gitignore 済み：雇用先・未公開の事情・個人情報を含む底稿はここ。**絶対に push しない**。
- 上流どうしが矛盾する、または出典のない公開文言が必要 → 手を止めて本人に聞く（CLAUDE.md）。
